راهنمای آپلود نسخه‌ی جدید سایت
=================================

۱. این زیپ را باز کن. داخلش این‌ها هست:
   index.html        ← صفحه‌ی انگلیسی جدید
   index-fa.html     ← فقط آدرس دو عکس عوض شده (عکس‌های سبک)
   css/custom.css    ← فایل جدید؛ همه‌ی استایل‌های شخصی تو اینجاست
   css/styles.css    ← فقط یک خط عوض شده (عکس پس‌زمینه‌ی سبک)
   images/...        ← عکس‌های فشرده‌شده + تصویرهای کارت پروژه‌ها

۲. برو به github.com/SepidehSepehri/sepidehsepehri.github.io
   Add file → Upload files
   پوشه‌های css و images و دو فایل html را با هم بکش و رها کن (drag & drop).
   گیت‌هاب ساختار پوشه‌ها را نگه می‌دارد و فایل‌های هم‌نام را جایگزین می‌کند.
   پایین صفحه: Commit changes

۳. خیلی مهم: فایل CV را دوباره آپلود کن، دقیقاً با همین اسم:
   Sepideh_Sepehri_CV_PHD.pdf
   (الان در ریپو نیست و دکمه‌های Download CV خطای 404 می‌دهند.)

۴. اختیاری: بعد از آپلود می‌توانی این سه فایل سنگین قدیمی را پاک کنی
   (دیگر هیچ صفحه‌ای از آن‌ها استفاده نمی‌کند):
   images/astro-tour.png   (۱۷ مگابایت)
   images/intro-bg.png     (۷ مگابایت)
   images/beyond-bg.png

۵. یکی دو دقیقه صبر کن تا GitHub Pages به‌روز شود، بعد سایت را با Ctrl+Shift+R باز کن.

جاهایی که داخل index.html برایت کامنت گذاشته‌ام (با <!-- شروع می‌شوند):
   - لینک arXiv مقاله (وقتی منتشر شد)
   - جای یک تصویر از کات‌اوت‌های JWST در بخش Research
   - لینک کد پروژه‌ی ML در GitHub
   - لینک کانال یوتیوب
   - ORCID در فوتر
   - برای عوض‌کردن تصویر هر کارت پروژه با نمودار واقعی خودت:
     آدرس src عکس همان کارت را عوض کن (مثلاً images/projects/wasp12b.png)
